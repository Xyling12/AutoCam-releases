# Сборки AutoCam

Здесь лежат только установщики AutoCam и файл описания последней версии.
**Исходного кода тут нет** — он в отдельном приватном репозитории.

Репозиторий публичный намеренно. Программа проверяет обновления сама, и чтобы
читать приватный репозиторий, ей понадобился бы токен доступа. Токен внутри
установленной программы достаётся любому, у кого есть установщик, — вместе с
обновлениями раздался бы доступ к исходникам. Поэтому секретов в программе нет
вообще, а наружу попадают только собранные установщики.

## Что здесь есть

- `latest.json` — номер последней версии, ссылка на установщик и его
  контрольная сумма. Этот файл программа и читает.
- Релизы с установщиками `AutoCam-Setup-<версия>-x64.exe`.

## Установка вручную

Скачайте установщик из последнего релиза и запустите. Программа обновится
сама, настройки и журналы останутся на месте.
